# Tennis Apps

A static landing page for two standalone tennis applications:

- [Tennis Strategy Simulator](./simulador-tenis.html) (Portuguese)
- [Tennis Scorecard](./tennis-scorecard.html) (English)

The original application files are published without modification. The landing
page is `index.html`; it uses relative links so it works under a GitHub Pages
repository path. Use the browser's Back button to return from either app.

## Publishing

GitHub Pages serves the root of the `main` branch. No build step or dependencies
are required. Push updates to `main` to publish them. `.nojekyll` disables Jekyll
processing so the HTML files are served as static assets.

Both application files and the landing page are publicly accessible.
